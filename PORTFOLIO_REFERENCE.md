## 🎬 Animation Timeline

```
Page Load:
  0ms   → Start loading animation
  1000ms→ Hide loader, show hero
  1500ms→ Stagger animations on hero
  2500ms→ Scroll hint animation starts

On Scroll:
  Enter viewport → Fade in + slide up
  Hover → Slight scale/color change
  Click → Button animation

Continuous:
  Gradient text → Color shift
  Scroll progress → Height animation
  Scroll hint → Up/down bounce
```
