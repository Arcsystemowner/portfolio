## ⚡ Common Tasks

### Deploy Your Portfolio (5 minutes)

1. Open [QUICK_START.md](./QUICK_START.md)
2. Choose Vercel (easiest), Netlify, or GitHub Pages
3. Follow the copy-paste commands
4. Your portfolio is live!

### Add Your Resume (10 minutes)

1. Create resume PDF
2. Save as `resume.pdf` in `portfolio/public/` folder
3. Test locally: `npm run dev`
4. Click "Download Resume" button
5. Deploy!

### Customize Portfolio Content (30 minutes)

1. Open [PORTFOLIO_SETUP.md](./PORTFOLIO_SETUP.md)
2. Find "File Locations for Updates" table
3. Edit files listed
4. Test locally
5. Deploy

### Get Custom Domain (15 minutes + 24-48 hours)

1. Buy domain at Namecheap (~$9/year)
2. See [DEPLOYMENT_GUIDE.md](./DEPLOYMENT_GUIDE.md) → "Custom Domain Setup"
3. Follow platform-specific instructions
4. Wait 24-48 hours for DNS propagation
